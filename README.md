# 轻办 (Lightwork)

本地优先的文档 / 图片 / 凭证处理工具台。单文件、离线运行，所有处理都在你的浏览器里完成，文件不上传任何服务器。

## 功能

- **凭证排版打印**：将零散凭证图片 / PDF 拼版到 A4，可旋转、排序，直接打印或导出 PDF。
- **图片 / PDF 压缩**：批量压缩图片与 PDF，可调画质、最大边长、输出格式。
- **图片格式转换**：在 JPEG / PNG / WebP / GIF / BMP / ICO / AVIF 等格式之间互转。
- **CDR 版本切换**：在 CorelDRAW 不同版本格式之间转换。

## 本地使用

直接双击 `index.html` 即可，无需安装、无需联网。
